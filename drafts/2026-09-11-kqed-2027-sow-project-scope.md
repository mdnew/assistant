# KQED 2026/2027 SOW: Project Scope

**Date:** September 11, 2026

---

Project Scope

The proposed scope of the project consists of working on the following new features and enhancements for the KQED mobile app:

Election 2026 Features
Improved Livestream Playback
Interactive Games & Community Features
Marketing Email Automation
App Store Optimization (ASO)
Audience Engagement & Retention

And the following features and enhancements on the new KQED web platform:

Upgrade and modernization of web site speed and optimization
Development of software to support content verticals, including food, technology, and experiences
Development of platforms to support user personalization
Shared APIs and backend services to support consistent functionality across platforms
DevOps, infrastructure, and deployment work required to support the above
Ongoing application security work

This work includes both client-side and server-side development, including the APIs, backend infrastructure, and analytics integration required to support the features above. Work will begin October 1st, 2026 and is expected to run through September 2027.
