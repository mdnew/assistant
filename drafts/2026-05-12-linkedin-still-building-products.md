# LinkedIn — May 12, 2026 (final)

After 25 years of doing this, I still like building products. Especially when the project is tightly scoped and the path to victory is relatively straightforward.

I still like thinking through the user stories, working through the designs, and then turning that into something we can ship and learn from.

I still like running development in JIRA so the whole team knows where we are and what done means.

I still like thinking through the analytics for the product. How we are going to know if it is successful, and what we need to pay attention to once we launch.

I like it all even more now that I can use AI to help me clear a lot of what I used to find tedious. No product person knows all the acceptance criteria up front, but now AI can help you get a lot closer before you hand off the ticket.

And I know that the developers like using AI to do the development for them because let's face it... typing all those lines of code was pretty tedious. Now they can focus on directing the right outcomes in the code.

I know it's all going to change. And I know some of you probably think I'm behind the curve already. But it just feels like things are actually in a really sweet spot right now. As long as you don't go too fast and make sure the team stays together.
